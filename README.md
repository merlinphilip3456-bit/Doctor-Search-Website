# Doctor-Search-Website

A simple Doctor Search web application built using PHP, MySQL, HTML, and CSS.

Users can search doctors by:
- Name
- Specialization
- Location

---

# Features

- Doctor search functionality
- Responsive card layout
- MySQL database integration
- PHP backend
- Clean UI design
- Hosted using InfinityFree

---

# Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- phpMyAdmin
- InfinityFree Hosting
